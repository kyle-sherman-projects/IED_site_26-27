Lesson 1.1

Design Basics

10 classes · APB 1.1.1–1.1.5

  • Class 1 · PLTW 1.1.1 Design as a Process: Instant Challenge (Duck Launch) — design, build, and test a rubber duckie launch device; represent results with a box plot What are effective ways to generate potential solutions to a problem?
  • Class 2 · PLTW 1.1.2 Iterate and Redesign (Day 1): compare class box plot data; define a measurable success criterion; begin redesign When solving an engineering problem, how can you reasonably ensure you have created the best solution possible?
  • Class 3 · PLTW 1.1.2 Iterate and Redesign (Day 2): retest redesigned device; calculate mean/median/range/IQR; identify outliers When solving an engineering problem, how can you reasonably ensure you have created the best solution possible?
  • Labor Day: Mon 9/7 (no school)
  • Class 4 · PLTW 1.1.3 Concept Sketching (Day 1): sketching technique demo; realistic proportion practice on everyday objects How is technical drawing similar to and different from artistic drawing?
  • Class 5 · PLTW 1.1.3 Concept Sketching (Day 2): structured peer feedback protocol; sketch revision; additional practice How is technical drawing similar to and different from artistic drawing?
  • Bonding Trip: Fri 9/11 (no class)
  • Class 6 · PLTW 1.1.4 Targeting Success Using Data (Day 1): coordinate-based landing data collection; accuracy vs. precision When solving an engineering problem, how can you reasonably ensure you have created the best solution possible?
  • Class 7 · PLTW 1.1.4 Targeting Success Using Data (Day 2): distance formula; quantify accuracy/precision; calculate a percentile-based target When solving an engineering problem, how can you reasonably ensure you have created the best solution possible?
  • Class 8 · PLTW 1.1.5 Project: Design a Game — A Carnival Game intro; define the problem; write a design brief What does consensus mean, and how do teams use consensus to make decisions?
  • Class 9 · PLTW 1.1.5 Project: Design a Game — generate individual concepts; decision matrix; select team design Is it ever advantageous to create a design individually as opposed to using a team approach?
  • Class 10 · PLTW 1.1.5 Unit 1 Problem introduced (Sweet Improvement, revisited in Problem 1.4.1) Project: Design a Game — construct and test prototype; write client proposal; project reflection In what ways can technical drawings help or hinder communication in a global community?
